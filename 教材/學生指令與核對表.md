# Day 2｜動手 3：用 opencode（agent）一步一步算事件研究的 CAR

> 學生用。每一格「指令」整段複製貼到 opencode；它做完後，照「核對」那一行檢查，對了才貼下一步。
> 核對數字是老師 2026-10-28 從 TEJ 匯出的資料算的，跟 TEJ 事件研究系統算出來的一樣到小數 4 位。**你的數先跟自己動手 1 的 TEJ 系統結果對**，一樣就是對；跟老師的數差在小數第 3–4 位是正常的（TEJ 會修正歷史資料），差到小數第 1–2 位或正負號不同，才是做錯。
> 實測：opencode＋gpt-oss:120b。2026-11-02 改成口語指令＋只有一般規矩的 AGENTS.md 後跑了 5 輪有效測試（A36、A38、A39、A41、A42）：五輪 7 步最後都過關，α、β、R²、CAR 都對到小數 4 位；兩輪一次都沒修，其他三輪各修 1–3 次。修的原因都一樣：它說「已執行」但畫面上沒有 `python stepN.py`（第 1、4 步各一次），或第 7 步它自己寫的 check.py 讀錯檔（兩次）。所以數字只信程式印出來的。
> 三個階段**各開一個新對話**（輸入 `/new`）；同一階段裡的步驟都在同一個對話裡做。

3. **把 opencode 整個關掉再重開**，讓它重新讀 `AGENTS.md`。`AGENTS.md` 只放跟 agent 做事的一般規矩（一步一步做、程式要真的跑、數字不能寫死……）；這個題目的細節（檔案長怎樣、存成什麼、欄位叫什麼）都寫在下面每一步的指令裡。

## 數字不對時

只講症狀（哪一步、哪個數字對不上），**不要把正確答案貼給它**，只修這一步，例如：

```
第 6 步的 CAR 跟核對值對不上。照 AGENTS.md 和第 6 步的指令，一項一項對，看哪裡沒照做，修好再跑一次，把程式印出來的結果給我看。不可以為了對上答案去改公式，也不可以把數字寫進程式。只修這一步。
```

**「不可以為了對上答案去改公式，也不可以把數字寫進程式」一定要留**：老師實測時，agent 知道正確答案後，曾經把答案寫進程式，也曾經改公式（只加正的 AR）去湊。

**數字只信程式印出來的**：它的回覆裡如果出現程式沒印出來的數字，不要信，要它跑程式印給你看。

**它說「已執行」，畫面上卻沒有 `python stepN.py` 那一格**：它沒跑，數字是編的。貼：

```
你沒有執行 stepN.py。請執行，把程式印出來的結果原樣貼給我。
```

**出現 Internal Server Error 或沒回應**：不是你做錯，是伺服器。同一段指令原封不動再貼一次。

## 階段一：做事件研究大表（第 1–3 步）

### 第 1 步

**指令**

```
第 1 步：data 資料夾裡有一個 TEJ 匯出的檔，幫我整理成一天一列：欄位叫 date、r_2887、r_2888、r_Y9997、v_2887、v_2888，日期從舊排到新，存成 s1.csv。代碼和日期當文字處理，不要變成數字；報酬率的單位是 %，照原樣不要換算。這個檔的編碼可能不是 UTF-8，中文讀不出來就換 Big5 試，每一格前後的空白要去掉。程式存成 step1.py，存好直接跑。跑完印給我看：原本幾列（不含欄名）、整理後幾天、第一天和最後一天是哪天、三個代碼各有幾天，天數要讀回 s1.csv 來數。把程式印出來的結果原樣貼給我。
```

**核對**：整理後 **481 天**；第一天 **20230103**、最後一天 **20241231**；三個代碼各 **481 天**；20240823 那天 r_2887 是 **3.1416**；畫面上要看到它執行 `python step1.py`

### 第 2 步

**指令**

```
第 2 步：幫 s1.csv 的每一天標上「相對日」，欄位叫 rel：20240823 那天是 0，它前一個交易日是 −1，後一個是 +1，以此類推。用交易日算，一列就是一天，停牌那天也算一天，不要用日曆天。rel 存整數，像 −10、0、1。存成 s2.csv，程式存成 step2.py，存好直接跑。印給我看 rel 是 −300、−51、−10、−1、0、+1 的那幾天各是哪一天。把程式印出來的結果原樣貼給我。
```

**核對**：rel −300＝**20230601**、−51＝**20240611**、−10＝**20240809**、−1＝**20240822**、0＝**20240823**、+1＝**20240826**

### 第 3 步

**指令**

```
第 3 步：幫我看事件窗（rel −10 到 +1）裡有沒有停牌日，成交量是 0 的那天就是。只是記下來，存成 halt.csv，欄位 code、date、rel、ret、vol，一個停牌日一列。s2.csv 不要動，停牌那天的資料也照原樣留著，不刪不改。程式存成 step3.py，存好直接跑。印給我看每家停牌幾天、是哪幾天、那天的報酬率是多少。把程式印出來的結果原樣貼給我。
```

**核對**：兩家都只有 **1 天**停牌：**20240822**（rel −1），報酬率 **0**、成交量 **0**

## 階段三：跑迴歸、算 CAR、自我檢查（第 5–7 步，開新對話）

### 第 5 步

**指令**

```
第 5 步：照 model.json，兩家各跑一條迴歸：Y 是那家的報酬，X 是大盤報酬，要有常數項。估計期那幾天用 s2.csv 的 rel 欄挑，不要用日曆天，也不要回去讀 data 的原始檔。程式存成 step5.py，存好直接跑，結果存成 params.csv，欄位 code、alpha、beta、r2、n（n 是用了幾天），小數存完整的。印給我看兩家的 alpha、beta、r2 和 n。把程式印出來的結果原樣貼給我。
```

**核對**：2887：alpha **−0.0241**、beta **0.4640**、r2 **0.2707**、n **250**；2888：alpha **−0.0214**、beta **0.5197**、r2 **0.1152**、n **250**。打開 `step5.py`，**裡面不可以出現這些數字**（要是迴歸算出來的）

### 第 6 步

**指令**

```
第 6 步：用 params.csv 的 alpha 和 beta，算事件窗每一天的異常報酬 AR：AR ＝ 那天的實際報酬 −（alpha ＋ beta × 那天的大盤報酬）。事件窗照 model.json，用 s2.csv 的 rel 欄挑。12 天的 AR 加起來就是 CAR。程式存成 step6.py，存好直接跑，結果存成兩個檔：ar.csv（欄位 code、date、rel、ret、mkt、normal、ar，每家一天一列）和 car.csv（欄位 code、car），小數存完整的。印給我看兩家每天的 AR 和 CAR。把程式印出來的結果原樣貼給我。
```

**核對**：每家 **12 列**；2887 在 rel 0 的 ar **3.1445**；CAR：2887 **9.4997**、2888 **20.1703**

### 第 7 步

**指令**

```
第 7 步：幫我寫一支 check.py 做檢查，只讀檔、不改任何檔。每一項印「通過」或「不通過」，後面附實際值：① rel 是 0 的那天是不是 20240823；② 兩家的估計期是不是都剛好 250 天；③ 每家的 AR 是不是剛好 12 天，rel −10 到 +1 一天都不缺；④ AR 加起來是不是等於 CAR；⑤ 你自己重算 rel 是 0 那天的 AR，跟 ar.csv 裡的一不一樣。④⑤ 差不到 0.0001 就算一樣。寫完跑給我看。
```

**核對**：5 項全部「通過」
