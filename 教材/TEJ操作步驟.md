# Day 2 TEJ 操作步驟（學生版，TEJ PRO）

> 這份有兩段，順序跟投影片一樣：**一、TEJ 事件研究系統**（動手 1）、**二、匯出報酬檔**（動手 2，動手 3 的 agent 要用）。
> 學校的 TEJ 已經從 TEJ+ 換成 **TEJ PRO**。匯出報酬檔有兩條路：TEJ PRO 軟體，或 TEJ Next 網頁（next.tejwin.com），二選一。
> 每一步都照畫面上的字。依據：2026-11-25 TEJ PRO 1.0.0.154 與 TEJ Next 實測（TEJ抓取回報 v15、v16）。

## 開始之前

1. **輸入法切成英數**：日期欄位只收數字，停在注音會打出中文字。
2. **先決定匯出走哪一條**：TEJ PRO 軟體，或 TEJ Next 網頁。TEJ PRO 打不開就走網頁。
3. **檔案最後放在你的工作資料夾裡的 `data` 資料夾**。

---

## 一、TEJ 事件研究系統（動手 1）

**一家跑一次**：先跑 2887，再跑 2888。兩家放在同一個專案裡，系統只會給你兩家的平均，不是任何一家的 CAR。

### 設定

| 項目 | 值 |
|---|---|
| 專案名稱 | `Day2_台新金_2887`（第二次 `Day2_新光金_2888`） |
| 資料市場／頻率／報酬率型態 | 台灣／日資料／連續複利報酬率 |
| 樣本 | 一筆：代碼 `2887`（或 `2888`），事件日 `20240823` |
| 方法 | OLS風險調整模式 |
| 估計期間 | `-300` ～ `-51` |
| 事件期間 | `-10` ～ `1` |
| 市場指數（左邊那組） | 上市／報酬指數 |
| 右邊那組 | 留在「請選擇...」 |

### 步驟

| 步驟 | 動作 |
|---|---|
| 0 | 桌面「TEJPro」→ 用自己申請的學校 Email（@nkust.edu.tw）登入。教室電腦**不要勾**「記住帳號密碼」 |
| 1 | 左上「功能選單」按 **「事件研究」**。會另外開「TEJ事件研究」程式，**要再登入一次**：帳號密碼看學校 TEJ PRO 網頁（tejpro.tej.com.tw/SchoolDoc/NKUST）的「程式說明」。功能選單縮成最左邊一條直立頁籤時，點那條頁籤就回來 |
| 2 | 資料類型頁：專案名稱、資料市場「台灣」、日資料、連續複利報酬率 → 下一步 |
| 3 | 事件日選擇頁：**先看清單是不是空的**，不是就全選 → 刪除。「證券代碼」打 `2887`、「事件日」打 `20240823` → 加入；確認「目前證券數：1 筆」→ 下一步 |
| 4 | 預期模式頁：方法點 **OLS風險調整模式**、估計期 −300～−51、事件期 −10～1。**左組指數改成「上市／報酬指數」** |
| 5 | 按「計算」，幾秒後出現「計算結果顯示」 |
| 6 | 「異常報酬」分頁 → 找「平均累積異常報酬率 CAR」那一列 × 「+1」那一欄 |
| 7 | 「估計彙總」分頁看 α（Alpha）、β（Beta(1)）、R²（R-Squared）、樣本數 |
| 8 | 結果視窗按「回主選單」，名稱改 `Day2_新光金_2888`，樣本換 2888、20240823，**左組指數再改一次**，再算 |

### 三個一定會遇到的坑

| 坑 | 你會看到 | 怎麼辦 |
|---|---|---|
| ① 左組指數 | 每次打開都停在「下市／不含航金」。不改就按計算 → `(3101)證券樣本過少或為零，無法計算任何結果。可檢視刪除樣本查看細節`。做第二家時又會變回來 | 改成「上市／報酬指數」再算 |
| ② 「事件日檢索」的「加入樣本」 | 會跳「事件日期欄位選項」：預設「以公告日」帶進 **20240822**；改選「以發生日」帶進 **20250724** | **兩個都不對。** 8/22 是停牌日，2025/7/24 是新光金下市日。刪掉，自己打 20240823 |
| ③ 預期模式的值 | 第一次打開是「平均調整模式、−260～−10、−3～3」；用過之後會記住上一次的設定，可能是別人的值 | 每一格都**確認**，不要以為是預設 |

另外：已經有樣本時，**不要再點一次「台灣」**，會跳「切換市場將清除所有已選事件樣本」，按確定樣本就清空。

### 做完對一下

| | α | β | R² | 樣本數 | CAR(−10,+1) |
|---|---|---|---|---|---|
| 2887 台新金 | −0.0241 | 0.4640 | 0.2707 | 250 | 9.4997 |
| 2888 新光金 | −0.0214 | 0.5197 | 0.1152 | 250 | 20.1703 |

等一下動手 3 agent 算的數字要跟這裡一樣（小數 4 位）。TEJ PRO 顯示 2887 的名稱是「台新新光金」。

## 二、匯出報酬檔（動手 2）

兩條路都用「**特殊轉檔**」，三個代碼一次匯出成一個檔。設定都一樣：

| 項目 | 值 |
|---|---|
| 資料表 | 台灣財經資料庫 › TEJ 股價資料庫 › 調整股價(日)-除權息調整 |
| 代碼 | `2887`、`2888`、`Y9997`（報酬指數） |
| 欄位 | `報酬率-Ln`、`成交量(千股)` |
| 期間 | `20230101` ～ `20241231` |
| 檔名 | `Day2_2887_2888_Y9997_20230101_20241231` |

### 路線 A：TEJ PRO 軟體

| 步驟 | 動作 |
|---|---|
| 1 | 功能選單按「資料查詢」，左邊選單樹：`台灣財經資料庫(TEJ TAIWAN DB) › TEJ 股價資料庫 › 調整股價(日)-除權息調整`，**雙擊** |
| 2 | 點工具列最左邊的「特殊轉檔」 |
| 3 | (2) 欄位設定：先按 `<<` 清空，只加 `報酬率-Ln`、`成交量(千股)` |
| 4 | (3) 選擇代碼：在「搜尋代號」框打 `2887`，**點一下反白那一列**，再按 `>`。`2888`、`Y9997` 照做 |
| 5 | (4) 期間設定：**先把「最近期」的勾拿掉**（不然日期框是灰的、只會匯出最後一天），再填起始 `20230101`、結束 `20241231` |
| 6 | 匯出類型 `.TXT`，按「存檔位置」→ 選你的工作資料夾裡的 `data` → 確定 |
| 7 | 按「開始轉檔」→ 跳「設定檔案名稱」，打 `Day2_2887_2888_Y9997_20230101_20241231`（不用打 .txt）→ 確定 |
| 8 | 跳出「下載完成，是否開啟下載目錄?」，按「是」 |
| 9 | data 裡是一個 **.zip**：右鍵「解壓縮全部...」，目的地照預設 |
| 10 | 解出來的 txt 檔名是一串時間（像 `20261125014847.txt`）：**改名**成 `Day2_2887_2888_Y9997_20230101_20241231.txt`，放回 `data` |
| 11 | 同名的 zip 和解壓縮多出來的空資料夾**移到別處**，`data` 裡只留這個 txt |

### 路線 B：TEJ Next 網頁

| 步驟 | 動作 |
|---|---|
| 1 | 瀏覽器打開 `next.tejwin.com`，右上「登入/註冊」登入 |
| 2 | 左側「資料庫偵探」→ 市場「台灣」→ `台灣財經資料庫 › TEJ 股價資料庫 › 調整股價(日)-除權息調整` |
| 3 | 上方「進階公司」→「公司查詢」框打 `2887`，**用滑鼠點跳出來的建議**（按 Enter 沒用）；`2888`、`Y9997` 照做 → 確定 |
| 4 | 日期框改打 `20230101-20241231` → Enter |
| 5 | **不要按右上的「報表匯出」**（一次只出一家，檔名都叫 data-explorer-results）。改點**左側「特殊轉檔」**：模組、三家、日期會自動帶過來 |
| 6 | 欄位設定只有報酬率-Ln，**再加上「成交量(千股)」** |
| 7 | 往下捲到「轉檔設定」：匯出類型 `.CSV`（預設），檔案名稱打 `Day2_2887_2888_Y9997_20230101_20241231` → 「開始轉檔」 |
| 8 | 右下「匯出任務」跑到 100% 會自動下載 zip 到「下載」資料夾 → 右鍵「解壓縮全部...」→ 裡面的 `.csv` 搬到工作資料夾的 `data`，`data` 裡只留這個 csv |

### 做完對一下

| 項目 | 路線 A：TEJ PRO（.txt） | 路線 B：TEJ Next（.csv） |
|---|---|---|
| 欄位 | 證券代碼、年月日、成交量(千股)、報酬率-Ln | 證券代碼、名稱、年月日、成交量(千股)、報酬率-Ln |
| 證券代碼那一欄 | `2887 台新新光金`（代碼和名稱同一欄） | `2887` |
| 編碼／分隔 | UTF-16、Tab | UTF-8、逗號 |
| 資料列數 | 1,443 列（三個代碼各 481 天） | 1,443 列 |
| 第一天／最後一天 | 20230103／20241231 | 20230103／20241231 |
| 20240822 那天 2887、2888 的成交量 | 0（停牌） | 0（停牌） |

對不上就重匯，不要往下做。動手 3 的第 1 步指令，兩條路各有一版（見 `學生指令與核對表.md`）。
