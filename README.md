# 金融市場與機構管理｜Day 2：金控宣布合併那幾天，股東賺了還是賠了？

這個資料夾就是你上課用的**工作資料夾**。下載下來之後，把 TEJ 匯出檔放進 `data`，在這個資料夾裡打開 opencode，照 `教材/學生指令與核對表.md` 一步一步做。

## 裡面有什麼

| 檔案 | 用途 |
|---|---|
| `AGENTS.md` | 給 opencode 看的工作規範：怎麼做事、這份資料怎麼讀、每一步存成什麼 |
| `data/` | 放你從 TEJ 匯出的 `Day2_2887_2888_Y9997_20230101_20241231.txt` |
| `教材/TEJ操作步驟.md` | TEJ 事件研究系統（動手 1）和匯出報酬檔（動手 2）的步驟 |
| `教材/學生指令與核對表.md` | 動手 3 要貼給 opencode 的 7 個指令，以及每一步的核對數字 |

## 怎麼下載

1. 開一個**新的、空的資料夾**當你的工作資料夾（放哪裡、叫什麼名字你自己決定）。動手 2 已經建好、`data` 裡放了 TEJ 檔的話，就用那個資料夾。
2. 在這個資料夾裡打開 opencode，貼這段：

   ```
   請用 git 把 https://github.com/guanyuhoujeff/2026-NKUST-FMgnt-day2.git 下載到目前這個資料夾，檔案直接放在這一層，不要多一層子資料夾；資料夾裡原本的檔案不可以刪除或覆蓋。下載完列出這一層的檔案。
   ```

3. **把 opencode 整個關掉再重開**，讓它重新讀 `AGENTS.md`。

電腦沒有 git 的話：在這個網頁按綠色的 **Code → Download ZIP**，解壓縮後把裡面的東西放進你的工作資料夾。

## 注意

- TEJ 匯出的資料**只能自己做研究用，不要上傳到任何公開的地方**（包括這個 repo 的 fork）。
- 核對表的數字是老師用 2026 年 10 月匯出的 TEJ 資料算的。你的數先跟自己用 TEJ 事件研究系統算的結果對；跟老師的數差在小數第 3–4 位是正常的（TEJ 會修正歷史資料），差到小數第 1–2 位或正負號不同，才是做錯。
