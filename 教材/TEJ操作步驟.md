# Day 2 TEJ 操作步驟（學生版）

> 這份有兩段，順序跟投影片一樣：**一、TEJ 事件研究系統**（動手 1）、**二、匯出報酬檔**（動手 2，動手 3 的 agent 要用）。
> 每一步都照畫面上的字。

## 開始之前（跟 Day 1 一樣）

1. **輸入法切成英數**：日期欄位只收數字，停在注音會打出中文字。
2. **TEJ+ 視窗拉寬，不要最大化**：太窄時「特殊轉檔」會被收進 `»` 選單。
3. **檔案存在你的工作資料夾裡的 `data` 資料夾**。

---

## 一、TEJ 事件研究系統（動手 1）

**一家跑一次**：先跑 2887，再跑 2888。兩家放在同一個專案裡，系統只會給你兩家的平均，不是任何一家的 CAR。

### 設定

| 項目 | 值 |
|---|---|
| 專案名稱 | `Day2_台新金_2887`（第二次 `Day2_新光金_2888`） |
| 資料市場／頻率／報酬率型態 | 台灣／日資料／連續複利報酬率 |
| 樣本 | 一筆：代碼 `2887`（或 `2888`），事件日 `20240823` |
| 方法 | OLS風險調整模式 |
| 估計期間 | `-300` ～ `-51` |
| 事件期間 | `-10` ～ `1` |
| 市場指數（左邊那組） | 上市／報酬指數 |
| 右邊那組 | 留在「請選擇...」 |

### 步驟

| 步驟 | 動作 |
|---|---|
| 1 | TEJ+ 選單樹**最下面**、跟「台灣財經資料庫」同一層的「TEJ 事件研究系統」，**雙擊** |
| 2 | 資料類型頁：專案名稱、資料市場「台灣」→ 下一步 |
| 3 | 事件日選擇頁：**先看清單是不是空的**，不是就全選 → 刪除。「證券代碼」打 `2887`、「事件日」打 `20240823` → 加入；確認「目前證券數：1 筆」 |
| 4 | 下一步 → 預期模式頁：**確認**是 OLS風險調整模式、估計期 −300～−51、事件期 −10～1。**左組指數改成「上市／報酬指數」** |
| 5 | 按「計算」，幾秒後出現「計算結果顯示」 |
| 6 | 「異常報酬」分頁 → 找「平均累積異常報酬率 CAR」那一列 × 「+1」那一欄 |
| 7 | 「估計彙總」分頁看 α、β、R²、樣本數 |
| 8 | 回主選單，2888 從步驟 2 再做一次 |

### 三個一定會遇到的坑

| 坑 | 你會看到 | 怎麼辦 |
|---|---|---|
| ① 左組指數 | 每次打開都停在「下市／不含航金」。不改就按計算 → `(3101)證券樣本過少或為零，無法計算任何結果`；「檢視刪除紀錄」寫 `(1101)估計期對應指數資料是空集合` | 改成「上市／報酬指數」再算 |
| ② 「事件日檢索」的「加入樣本」 | 會跳「事件日期欄位選項」：預設「以公告日」帶進 **20240822**；改選「以發生日」帶進 **20250724** | **兩個都不對。** 8/22 是停牌日，2025/7/24 是新光金下市日。刪掉，自己打 20240823 |
| ③ 系統會記住上一個人的設定 | 估計期、事件期、方法可能已經填好，也可能是別人的值 | 每一格都**確認**，不要以為是預設 |

### 做完對一下

| | α | β | R² | 樣本數 | CAR(−10,+1) |
|---|---|---|---|---|---|
| 2887 台新金 | −0.0241 | 0.4640 | 0.2707 | 250 | 9.4997 |
| 2888 新光金 | −0.0214 | 0.5197 | 0.1152 | 250 | 20.1703 |

等一下動手 3 agent 算的數字要跟這裡一樣（小數 4 位）。

## 二、匯出報酬檔（動手 2）

做完你會得到 **1 個檔**：`Day2_2887_2888_Y9997_20230101_20241231.txt`。

| 步驟 | 動作 |
|---|---|
| 1 | 左邊選單樹：`台灣財經資料庫(TEJ TAIWAN DB) › TEJ 股價資料庫 › 調整股價(日)-除權息調整`，**雙擊** |
| 2 | 點工具列「特殊轉檔」 |
| 3 | **代碼設定**：先按 `<<` 清空。在右上角**那個沒有字的空白框**打 `2887`，左邊清單會跳到並反白 `2887`，**點一下那一列**，再按 `>`。`2888`、`Y9997` 照做 |
| 4 | **欄位設定**：先按 `<<` 清空，只加 `報酬率-Ln`、`成交量(千股)` 兩個 |
| 5 | **期間設定**：起始 `20230101`、結束 `20241231` |
| 6 | 「存檔位置」打 `你的工作資料夾\data\Day2_2887_2888_Y9997_20230101_20241231.txt` |
| 7 | 「開始轉檔」→「傳送家數輸入」數字不用改，按「確定」 |
| 8 | 跳出 `Export data to file successfully(...)!!`，按「OK」 |

**容易卡的地方：**
- 步驟 3 那個空白框**沒有任何提示字**，看不出它是搜尋框。`Y9997 報酬指數`在清單最後面，用捲的要捲很久，用打的比較快。
- 打完代碼**要再點一下反白那一列**才會加進右邊，只打字不會。

**做完對一下：**

| 項目 | 應該是 |
|---|---|
| 欄位 | `證券代碼 簡稱 年月日 報酬率-Ln 成交量(千股)`（前三欄是 TEJ 自動帶的） |
| 資料列數 | 1,443 列（三個代碼各 481 天） |
| 第一天／最後一天 | 20230103／20241231 |
| 20240822 那天 2887、2888 的成交量 | 0（停牌） |

## 附：事件日從哪裡來（不用每人都查，老師示範）

| 要什麼 | 去哪裡 | 看到什麼 |
|---|---|---|
| 公告日與**時間** | 公開資訊觀測站 → 重大訊息/公告 → 重大訊息查詢 → **歷史重大訊息**，公司代號 `2887`、113 年 8 月 | 113/08/22 **21:31:10** 合併公告（收盤後）；8/21 19:00:13 公告 8/22 暫停交易；8/22 21:35:26 公告 8/23 恢復交易 |
| 公告日（核對用） | TEJ+ 特殊事件日期資料庫，代碼 `N1TSE 上市合併事件(被併消滅)`，期間**不要改** | 掛在 **2887** 底下：公告日 20240822（**沒有時間**）、事件日 20250724（＝下市日，不是我們要的） |

所以事件日是 **20240823**：消息在 8/22 收盤後才公布，8/22 又整天停牌，8/23 是市場第一次能交易這個消息的日子。
