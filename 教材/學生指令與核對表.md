# Day 2｜動手 3：用 opencode（agent）一步一步算事件研究的 CAR

> 學生用。7 個任務拆成 18 段短指令（每段不到 100 字）。每一段整段複製貼到 opencode，**貼一段、等它做完停下來、照「核對」檢查、對了再貼下一段**；一次貼好幾段它會跳步。每段下面有「為什麼這樣寫」：指令裡的字（Big5、欄位名、rel……）是什麼意思、為什麼不能少，貼之前先看一眼。
> 核對數字是老師 2026-10-28 從 TEJ 匯出的資料算的，跟 TEJ 事件研究系統算出來的一樣到小數 4 位。**你的數先跟自己動手 1 的 TEJ 系統結果對**，一樣就是對；跟老師的數差在小數第 3–4 位是正常的（TEJ 會修正歷史資料），差到小數第 1–2 位或正負號不同，才是做錯。
> 實測：opencode＋gpt-oss:120b。2026-11-03 把 7 步拆成 18 段短指令（每段不到 100 字，v20），搭配 9 條規矩的 AGENTS.md 跑了 6 輪完整測試（B7、B9、B11–B14）：六輪 18 步最後全部過關，α、β、R²、CAR 都對到小數 4 位；一次就對的步數 14–16/18，其餘送修 1–2 次就過。送修原因：它說「已執行」但畫面上沒有 `python stepN.py`（第 11、12、17 步合計 6 次）、`s1.csv` 多算 1 列（第 2 步 3 輪）、它自己寫的 check.py 把日期讀成 20240823.0 判成不通過（第 17 步 3 輪）、`rel` 有空值（第 4 步 2 輪）、`model.json` 沒存或 est 寫錯（第 10 步 1 輪）、迴歸拿成交量當 Y（第 12 步 1 輪；之後把 Y 的欄名寫進指令，再測 2 輪沒再發生）。壓到 100 字以內後實測不能少的字：欄位名、「不用日曆天」、「空白去掉」、「不要放進 data」、「est、win 各放起迄兩個 rel 數字」、Y 用哪個欄。所以數字只信程式印出來的。

## 數字不對時

只講症狀（哪一步、哪個數字對不上），**不要把正確答案貼給它**，只修這一步，例如：

```

```

**「不可以為了對上答案去改公式，也不可以把數字寫進程式」一定要留**：老師實測時，agent 知道正確答案後，曾經把答案寫進程式，也曾經改公式（只加正的 AR）去湊。

**數字只信程式印出來的**：它的回覆裡如果出現程式沒印出來的數字，不要信，要它跑程式印給你看。

**它說「已執行」，畫面上卻沒有 `python stepN.py` 那一格**：它沒跑，數字是編的。貼：

```
你沒有執行 stepN.py。請執行，把程式印出來的結果原樣貼給我。
```

**出現 Internal Server Error 或沒回應**：不是你做錯，是伺服器。同一段指令原封不動再貼一次。

## 階段一：做事件研究大表（任務 1–3，第 1–7 步）

### 任務 1｜整理成一天一列（第 1–3 步）

**第 1 步｜指令**

```
第 1 步：讀 data 裡的 TEJ 匯出檔：UTF-8 讀不出中文就換 Big5，每格前後空白去掉，代碼和日期當文字，報酬率照原樣。告訴我有幾列、哪些欄位、哪三個代碼，先不要存檔。
```

**為什麼這樣寫**

- 「讀 data 裡的 TEJ 匯出檔」：動手 2 存的那個 txt。它在 data 裡，agent 要自己找到。
- 「UTF-8 讀不出中文就換 Big5」：中文有兩種常見存法。TEJ 匯出的是舊的 Big5，Python 預設用 UTF-8 讀，會亂碼或直接報錯。
- 「每格前後空白去掉」：TEJ 每一格前後都有空格，像「2887   」。不去掉，「2887   」跟「2887」會被當成兩個代碼。
- 「代碼和日期當文字」：當成數字會出事：代碼 0050 會變 50，日期 20240823 可能變 20240823.0，之後對不起來。
- 「報酬率照原樣」：不四捨五入、不換單位。TEJ 給的是「報酬率-Ln」，單位是 %。
- 「先不要存檔」：第 1 步只是看資料長怎樣：幾列、哪些欄、三個代碼都在嗎。確認了才動手整理。

**核對**：它回報的三個代碼是 **2887、2888、Y9997**，欄位裡有日期、報酬率、成交量；這一步**不存檔**

**第 2 步｜指令**

```
第 2 步：整理成一天一列，欄位 date、r_2887、r_2888、r_Y9997、v_2887、v_2888，日期由舊到新。存 s1.csv，不要放進 data；存 step2.py 並執行。
```

**為什麼這樣寫**

- 「整理成一天一列」：TEJ 是長表：一個代碼一天一列，1,443 列。迴歸要同一天的台新金報酬和大盤報酬在同一列，所以轉成 481 列。
- 「date」：交易日，格式 20240823。週末、假日本來就不在檔裡。
- 「r_2887、r_2888」：台新金、新光金當天的對數報酬率（%），是迴歸的 Y。r 是 return。
- 「r_Y9997」：加權指數當天的報酬率，代表大盤，是市場模型的 X。
- 「v_2887、v_2888」：成交量（千股），只在任務 3 找停牌日用。指數沒有成交量，所以沒有 v_Y9997。v 是 volume。
- 「日期由舊到新」：任務 2 的 rel 是沿交易日往前往後數，順序反了 rel 就反。CAR 也是照時間加。
- 「存 s1.csv，不要放進 data；存 step2.py 並執行」：data 裡只放 TEJ 原檔，自己做的檔放外面。程式要存檔、要真的跑（AGENTS.md 第 3 條），沒跑就是它編的。

**核對**：工作資料夾裡多了 `s1.csv`（不在 `data` 裡），欄位是 `date、r_2887、r_2888、r_Y9997、v_2887、v_2888`；畫面上要看到它執行 `python step2.py`

**第 3 步｜指令**

```
第 3 步：寫 step3.py 讀回 s1.csv，印出整理後幾天、第一天和最後一天、三個代碼各幾天。存好直接跑。
```

**為什麼這樣寫**

- 「讀回 s1.csv，印幾天、第一天和最後一天、三個代碼各幾天」：AGENTS.md 第 6 條：幾天要用程式從存好的檔讀回來數，不是 agent 嘴巴說。三個都 481 天才代表沒缺日，缺了後面同一天就對不齊。

**核對**：整理後 **481 天**；第一天 **20230103**、最後一天 **20241231**；三個代碼各 **481 天**；畫面上要看到它執行 `python step3.py`

### 任務 2｜標相對日 rel（第 4–5 步）

**第 4 步｜指令**

```
第 4 步：幫 s1.csv 加一欄 rel：20240823 是 0，前一個交易日 −1，後一個 +1；用交易日數，停牌日也算一天，不用日曆天。存 s2.csv，程式存 step4.py 並執行。
```

**為什麼這樣寫**

- 「rel」：相對日：事件日 20240823 是 0，前一個交易日 −1，後一個 +1。估計期（−300～−51）和事件窗（−10～+1）都用它定義。
- 「用交易日數，不用日曆天」：DeLong 用交易日。用日曆天，−300 會跑到 2023 年 10 月，估計期少掉一百多天。
- 「停牌日也算一天」：20240822 停牌那列還在檔裡，數的時候不跳過。DeLong 沒寫停牌怎麼辦，這是我們自己定的，收尾討論 2 再談。
- 「存 s2.csv」：s1 加一欄 rel。之後每一步都讀 s2，不再碰 s1，也不動 TEJ 原檔。

**核對**：多了 `s2.csv`，比 `s1.csv` 多一欄 `rel`；畫面上要看到它執行 `python step4.py`

**第 5 步｜指令**

```
第 5 步：寫 step5.py 讀 s2.csv，印出 rel 是 −300、−51、−10、−1、0、+1 的日期。存好直接跑。
```

**為什麼這樣寫**

- 「印出 rel −300、−51、−10、−1、0、+1 的日期」：這六天是估計期頭尾、事件窗頭尾、事件日和它前一天。六個日期都對，rel 才算對。

**核對**：rel −300＝**20230601**、−51＝**20240611**、−10＝**20240809**、−1＝**20240822**、0＝**20240823**、+1＝**20240826**

### 任務 3｜找停牌日（第 6–7 步）

**第 6 步｜指令**

```
第 6 步：事件窗（rel −10 到 +1）成交量 0 的停牌日，只列那幾列，存 halt.csv（code、date、rel、ret、vol），s2.csv 不要改。存 step6.py 並執行。
```

**為什麼這樣寫**

- 「事件窗（rel −10 到 +1）」：只查事件窗：這 12 天的報酬會直接加進 CAR，停牌的 0 會把 CAR 拉低。

- 「s2.csv 不要改」：這一步只檢查、不處理。停牌日要不要刪是收尾討論 2 的題目，現在的規則是照原值留著。

**核對**：多了 `halt.csv`（欄位 `code、date、rel、ret、vol`），`s2.csv` 沒被改；畫面上要看到它執行 `python step6.py`

**第 7 步｜指令**

```
第 7 步：寫 step7.py 讀 halt.csv，印出每家停牌哪幾天、那天報酬率多少。存好直接跑。
```

**為什麼這樣寫**

- 「讀 halt.csv，印每家停牌哪幾天」：用程式讀回來印，不是看第 6 步的回報。核對：兩家都只有 20240822 一天。

**核對**：兩家都只有 **1 天**停牌：**20240822**（rel −1），報酬率 **0**、成交量 **0**

## 階段二：下你的研究模型（任務 4，第 8–11 步，開新對話）

**核對**：它用中文複述的跟你講的一樣：市場模型、大盤 `r_Y9997`、事件日 20240823、估計期 −300～−51、事件窗 −10～+1、2887 用 `r_2887`、2888 用 `r_2888`


**為什麼這樣寫**

- 「code、date、rel、ret、mkt、normal、ar」：代碼、日期、相對日、實際報酬、大盤報酬、正常報酬（α＋β×大盤）、異常報酬。每一欄都存，核對時才看得出是哪一步錯。
